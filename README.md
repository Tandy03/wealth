# Investment Tracker

Personal investment portfolio tracker built with:

- HTML
- CSS
- Vanilla JavaScript
- Node.js
- Express
- JSON data storage

## Requirements

Install Node.js LTS.

## Run locally

Open the project folder in VS Code or PyCharm terminal:

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

The API and frontend are served by the same local Node.js server.

## Current functionality

- Dark UI
- Dashboard
- Portfolio table
- Add asset
- Delete asset
- JSON persistence through API
- Basic transaction structure
- Payment structure
- Calendar notes structure

## Data

All application data is stored in:

`backend/data/data.json`
